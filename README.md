A project that uses github workflows to compile raygui binaries for all platforms!

To Use
------

1. Clone this repo.
2. Place raylib binaries in the lib/ folder (used for shared binaries).
3. Place raylib.h and raygui.h in the input/ folder.
4. Publish to github!

Every time a push is done, binaries will automatically be generated  
in GitHub Actions, which can be found on the Actions page of your local repo.
